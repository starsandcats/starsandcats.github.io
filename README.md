I am stars! 
I like to draw!
Here is a simple guide on how to make this portfolio website! 

This site was built with:
HTML for website structure and content.
CSS for the layout, typography, colors, and responsive styling.
and with GitHub Pages that is hosting directly from this repository (for free btw!) 

The main portfolio page and website code is structured as such: 
index.html
images/ for the assets that will be used as a base for where all the images, gifs, and videos will be stored
images/illustration/ is for the illustration files
images/animation/ for the animation files
images/sketches/ for the sketch files 
and make README.md for documentation a step by step guide like this or even just to put something fun for others to find

TLDR; The index.html file is the homepage and the HTML connects the gallery to the artwork stored in the repository 

For updating when you go to the repository upload everything to the appropriate folders by goig to add file then upload file 

Edit the index.html to add new galleries and other sections of your website
*ITS IMPORTANT THAT YOU MAKE SURE EACH IMAGE PATH AND FILENAME MATCHES THE UPLOADED FILE EXACTLY INCLUDING CAPITALIZATION AND FILE EXTENSION* when you do not do this there will be a "image not found" in place of the image

if the site fails or anything check the settings then the pages and actions tabs if the site will not update or a deployment error
